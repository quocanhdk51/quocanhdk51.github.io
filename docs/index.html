04 · How I work

I direct agents,
and I own the result.

I built a Claude Code plugin with a spec-driven pipeline. Every feature passes through six gates, each with acceptance scenarios, design boards and a build that has to be green. The agents do the typing. I make the decisions and review every diff.

  1. 01SpecifyProblem, outcomes, BDD scenarios
  2. 02DesignBoards for every screen state
  3. 03PlanChanges mapped to scenarios and risks
  4. 04ImplementParallel builders on a green build gate
  5. 05ReviewFresh-eyes reviewers, verified findings
  6. 06ValidateUnit, API and e2e tests, docs, PRs
